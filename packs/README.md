# Starter packs

Four agents per pack, picked for one kind of business. Start with a pack, not with all 283.

Install one into your project:

```bash
./install.sh streetwear-brand
```

| Pack | For | Agents |
| --- | --- | --- |
| [Streetwear brand](streetwear-brand.md) | For a clothing or merch brand selling online and growing on Instagram. | 21 Brand Guardian, 21 Instagram Curator, 21 Frontend Developer, 21 Customer Service |
| [Online shop](online-shop.md) | For any small e-commerce store that needs traffic and happy customers. | 21 Frontend Developer, 21 SEO Specialist, 21 Paid Social Strategist, 21 Customer Service |
| [Content creator](content-creator.md) | For creators who post daily and want to grow faster. | 21 Content Creator, 21 TikTok Strategist, 21 Instagram Curator, 21 Carousel Growth Engine |
| [Solo developer](solo-developer.md) | For one person building and shipping an app or SaaS. | 21 Senior Developer, 21 Code Reviewer, 21 Reality Checker, 21 AI-Generated Code Security Auditor |
| [Local business](local-business.md) | For a cafe, studio, salon or shop with a physical location. | 21 Social Media Strategist, 21 SEO Specialist, 21 Customer Service, 21 Bookkeeper & Controller |
| [Freelancer](freelancer.md) | For designers, developers and creatives who sell their own services. | 21 Outbound Strategist, 21 Proposal Strategist, 21 Project Shepherd, 21 UI Designer |
