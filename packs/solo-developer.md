# Solo developer pack

For one person building and shipping an app or SaaS.

| Agent | What it does for you |
| --- | --- |
| [21 Senior Developer](../agents/engineering/21-senior-developer.md) | Builds features with clean, simple code. |
| [21 Code Reviewer](../agents/engineering/21-code-reviewer.md) | Finds the real bugs before users do. |
| [21 Reality Checker](../agents/testing/21-reality-checker.md) | Says honestly if it is ready to ship. |
| [21 AI-Generated Code Security Auditor](../agents/security/21-ai-generated-code-security-auditor.md) | Checks AI-written code for security holes. |

## Install

```bash
./install.sh solo-developer
```

Then ask by name, for example: "Use 21 Senior Developer to review our homepage."
