# Content creator pack

For creators who post daily and want to grow faster.

| Agent | What it does for you |
| --- | --- |
| [21 Content Creator](../agents/marketing/21-content-creator.md) | Turns ideas into posts, scripts and captions. |
| [21 TikTok Strategist](../agents/marketing/21-tiktok-strategist.md) | Plans short videos that get watched. |
| [21 Instagram Curator](../agents/marketing/21-instagram-curator.md) | Shapes the Instagram feed and stories. |
| [21 Carousel Growth Engine](../agents/marketing/21-carousel-growth-engine.md) | Builds carousels people save and share. |

## Install

```bash
./install.sh content-creator
```

Then ask by name, for example: "Use 21 Content Creator to review our homepage."
