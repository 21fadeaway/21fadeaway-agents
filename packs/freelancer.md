# Freelancer pack

For designers, developers and creatives who sell their own services.

| Agent | What it does for you |
| --- | --- |
| [21 Outbound Strategist](../agents/sales/21-outbound-strategist.md) | Finds and contacts the right clients. |
| [21 Proposal Strategist](../agents/sales/21-proposal-strategist.md) | Writes proposals that win. |
| [21 Project Shepherd](../agents/project-management/21-project-shepherd.md) | Keeps every project on time. |
| [21 UI Designer](../agents/design/21-ui-designer.md) | Makes the work look premium. |

## Install

```bash
./install.sh freelancer
```

Then ask by name, for example: "Use 21 Outbound Strategist to review our homepage."
