# Streetwear brand pack

For a clothing or merch brand selling online and growing on Instagram.

| Agent | What it does for you |
| --- | --- |
| [21 Brand Guardian](../agents/design/21-brand-guardian.md) | Keeps every page, post and drop on-brand. |
| [21 Instagram Curator](../agents/marketing/21-instagram-curator.md) | Plans the feed, carousels and stories. |
| [21 Frontend Developer](../agents/engineering/21-frontend-developer.md) | Builds and fixes the store site. |
| [21 Customer Service](../agents/specialized/21-customer-service.md) | Answers orders, shipping and returns. |

## Install

```bash
./install.sh streetwear-brand
```

Then ask by name, for example: "Use 21 Brand Guardian to review our homepage."
