# Online shop pack

For any small e-commerce store that needs traffic and happy customers.

| Agent | What it does for you |
| --- | --- |
| [21 Frontend Developer](../agents/engineering/21-frontend-developer.md) | Keeps the shop fast and working on phones. |
| [21 SEO Specialist](../agents/marketing/21-seo-specialist.md) | Gets product pages found on Google. |
| [21 Paid Social Strategist](../agents/paid-media/21-paid-social-strategist.md) | Runs small, careful ad tests. |
| [21 Customer Service](../agents/specialized/21-customer-service.md) | Handles customer emails and DMs. |

## Install

```bash
./install.sh online-shop
```

Then ask by name, for example: "Use 21 Frontend Developer to review our homepage."
